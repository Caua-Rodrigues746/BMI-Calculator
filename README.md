# Simple BMI Calculator

A simple BMI (Body Mass Index) calculator built with Python.

## Features

- Allows the user to enter their weight in kilograms and height in meters to calculate BMI.
- Uses a separate Python module (`functions.py`) to organize reusable functions.
- Validates weight and height to prevent zero or negative values.
- Handles invalid numeric input.
- Displays the BMI result to two decimal places.
- Allows the user to perform multiple calculations without restarting the program.

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Make sure `bmi_calculator.py` and `functions.py` are in the same directory.
4. Open a terminal in that directory and run:

```bash
python bmi_calculator.py
```
